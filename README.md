## 📖 About

This repo collects the practical stuff I wish I had when starting out: a clear roadmap, a modern tech stack, starter project layouts, and a curated list of resources for **web** and **mobile** app development.

It's not a tutorial series — it's a **reference and starting point**. Fork it, trim it, make it yours.

**Who it's for:**
- Beginners who want a structured path instead of random YouTube tabs
- Developers moving from web → mobile (or vice versa)
- Anyone who wants a sane default project structure and toolchain

## 🧰 Tech Stack

### Web

| Layer | Choices | Notes |
|---|---|---|
| Language | TypeScript (preferred), JavaScript | Types save you at 2am |
| Framework | React, Next.js, Vue, SvelteKit | Next.js for SSR/SEO-heavy apps |
| Styling | Tailwind CSS, CSS Modules, shadcn/ui | Utility-first for speed |
| State | Zustand, Redux Toolkit, TanStack Query | Query for server state |
| Backend | Node.js (Express/Fastify), Next API routes, Supabase | Start simple |
| Database | PostgreSQL, SQLite, MongoDB | Postgres unless you have a reason |
| Testing | Vitest, Playwright, React Testing Library | Unit + E2E |
| Deploy | Vercel, Netlify, Cloudflare Pages | Free tiers are generous |

### Mobile

| Layer | Choices | Notes |
|---|---|---|
| Cross-platform | React Native (Expo), Flutter | Expo = fastest start |
| Native | Swift (iOS), Kotlin (Android) | Best perf & platform APIs |
| Navigation | Expo Router, React Navigation, go_router | File-based routing is nice |
| Storage | AsyncStorage, MMKV, SQLite, WatermelonDB | MMKV for speed |
| Backend | Same as web (REST/GraphQL) + Firebase/Supabase | Reuse your API |
| Testing | Jest, Detox, Maestro | Maestro for E2E flows |
| Release | EAS Build, Fastlane, Codemagic | Automate the boring parts |
